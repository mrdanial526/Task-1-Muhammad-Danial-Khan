## 🌟 Key Features

- **Semantic HTML5 Architecture**: Implements semantic landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<dialog>`) with strict WCAG 2.1 AA accessibility compliance.
- **Custom CSS Design System**: Built with modern CSS Grid & Flexbox, custom CSS properties (design tokens), fluid typography, and dark mode glassmorphism.
- **Interactive Solutions Filtering**: Dynamic category filtering for engineering solutions with live ARIA announcements and empty fallback states.
- **Native Solution Inspector (`<dialog>`)**: Interactive modal popup with architecture blueprints and one-click clipboard copying.
- **Deterministic Sequential ScrollSpy**: Real-time header and sidebar table-of-contents navigation highlighting active sections on scroll.
- **Accessible Mobile Navigation Drawer**: Keyboard-accessible drawer with focus trapping and ESC key dismissal.
- **Client-Side Form Validation**: Accessible interactive contact form with real-time error handling.
- **Real-Time Performance Telemetry**: Measures DOM load readiness using the Performance API.
